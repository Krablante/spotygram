# Spotygram 0.9.1 — выбор песен после возвращения из фона

Исправлено ложное **«Плеер подключается…»** при выборе другой песни после
повторного открытия приложения. Строки списка могли сохранять старый обработчик
с null-контроллером, хотя мини-плеер уже работал. Теперь обработчики получают
актуальные зависимости; исправлен и аналогичный риск у действий с любимыми.

Подключение UI к плееру восстанавливается при возвращении в приложение и
обрабатывает разрыв связи. Повторы ограничены, фонового цикла переподключения нет.
Если нажать на песню во время настоящего подключения, последний выбор выполнится
после готовности. Сообщение об ожидании исчезает после подключения или ошибки.
При неудаче можно повторить выбор песни без перезапуска приложения.

Уход из приложения отменяет ещё не выполненный запрос, но не останавливает
уже играющую музыку. Библиотека, настройки, плейлисты и подпись APK сохраняются.

## English

Fixed a stale **Connecting to player…** message when selecting another song after
reopening the app. List rows could retain a handler with an old null controller
even while the mini-player worked. Playback and group-favorite callbacks now
receive current dependencies.

The UI reconnects on foreground entry and handles disconnection with bounded
attempts, not a background retry loop. A song selected while connecting starts
once ready; only the latest selection is kept. The waiting message clears when
the request settles. A failed connection can be retried by tapping a song.
Leaving cancels an unfulfilled start, not music already playing. Existing
library data, playlists, settings and the APK signing key are preserved.
