# 0.10.2 — clearer light and dark glass

The full-screen spectrum and grid no longer run behind track names, playlists,
or controls. Light mode has a pale neutral ground; dark mode has a near-black
one. Glass surfaces use layered translucent fills, reflected edges and a denser
core for readable text. Album art and selected controls carry the color.

The four destinations, playback controls, library and settings work as before.
The full player hides the inactive download action for a track already saved
on the device, leaving the queue control readable on narrow screens.
No music, playlist or Telegram data migration is needed.
