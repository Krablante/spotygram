# 0.11.0 — a clearer Liquid Glass interface

The library now uses a clean, near-white or near-black canvas. Color comes from
artwork and selected controls instead of a rainbow background. Songs, playlists
and chats remain plain content; search, selectors, the player controls and the
floating dock form the control layer. The dock uses Haze Glass to sample and
refract the page beneath it, with a denser tint where passing text would make
the controls hard to read.

The full player keeps its transport visible on short phones, while the remaining
actions stay accessible by scrolling. The compact player truncates long titles
cleanly. This update keeps the same package, signing key and local library.
Android 8.0 remains the minimum supported version. Build instructions now use
SDK 37.0, AGP 9.1.1, Kotlin 2.4.20 and Gradle 9.3.1.

Download the ARM64 APK for a phone. The x86-64 APK is for compatible Android
environments. Manual emulator checks and their limits are in
[verification.md](../verification.md).
