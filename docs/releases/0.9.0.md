# Spotygram 0.9.0 — скрывать дубли

Новый переключатель **Настройки → Скрывать дубли**, включённый по умолчанию.
Повторяющиеся записи в «Музыке», «Любимых» и «На телефоне» показываются одной
строкой. Выключение возвращает отдельные записи; файлы и сообщения не удаляются.

Совпадения определяются по одному файлу Telegram, общему локальному пути либо
совпадающим названию, исполнителю, длительности и размеру файла. Одного названия
недостаточно. Это сравнение метаданных, не распознавание звука.

Поиск и фильтр чатов сохраняются. При выборе копии предпочтение отдаётся
сохранённой локальной. Любимые учитывают скрытые дубли и поддерживают отмену.
Новая очередь из списка не содержит скрытых повторов; готовые плейлисты и
текущая очередь не переписываются. Абсолютный рандом всё ещё может выбрать
одну песню несколько раз. Объём хранилища учитывает и скрытые файлы.

## English

New **Settings → Hide duplicates** switch, on by default. Music, Favorites and
On device show one row per matching recording. Switching it off restores
separate entries; no files or messages are deleted.

Matching uses Telegram file identity, a shared path, or equal title, artist,
duration and byte size—not title alone or acoustic recognition. Search/source
filters run first, and a retained local copy is preferred. Group favorites
support exact Undo. New queues use the grouped list; existing playlists and
the current queue stay unchanged. Absolute random may still repeat songs.
Storage size includes hidden physical copies.
