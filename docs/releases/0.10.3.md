# 0.10.3 — restore the 0.10.1 interface

This release restores the 0.10.1 light and dark appearance, including its
background, glass surfaces, artwork, navigation and player controls. The 0.10.2
redesign has been withdrawn.

The higher version number lets Android install the restoration over 0.10.2
without removing local music, playlists or your Telegram session. There are
no library or account migrations.
