# 0.10.1 — full-spectrum colors

The 0.10.0 interface leaned too heavily on violet. This update replaces its
background and control colors with a balanced red-to-violet spectrum over a
neutral light or dark base. Color appears in separate areas and light bands;
the glass surfaces remain clear enough to read long music lists. Favorites,
active tracks, navigation destinations and fallback artwork use distinct
accents instead of one shared hue.

The launcher icon, Android window colors and README banner follow the same
palette. No music, playlist or Telegram data migration is involved.
