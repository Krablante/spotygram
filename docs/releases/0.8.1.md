# Spotygram 0.8.1 — предыдущий трек в мини-плеере

В нижнем мини-плеере теперь три кнопки: **предыдущий трек · пауза/воспроизведение · следующий трек**.
Кнопка назад сразу переключает на предыдущую песню, в том числе по истории
абсолютного рандома. Открывать большой плеер для этого больше не нужно.
Длинные названия сокращаются многоточием, кнопки сохраняют обычные области нажатия.

## English

The bottom mini-player now has **previous · play/pause · next** controls.
Previous goes directly to the previous song, including absolute-random history,
without opening the full player. Long titles ellipsize while controls retain
their normal touch targets.
