# Spotygram 0.7.0

Download and install updates without leaving the app to find an APK on GitHub.

- Both automatic update offers and Settings include **Download and install**.
- Android DownloadManager handles the transfer, including background continuation. The app shows progress and cancellation and restores the transfer after a restart.
- Before installation, Spotygram checks the APK's size, SHA-256, package, version and signing certificate. Android then asks for installation confirmation.
- If Android needs permission to install from Spotygram, returning from that screen continues the request. Denial and cancellation do not cause repeated prompts.
- A downloaded APK can be installed again without downloading it again, or deleted. Temporary data is removed on cancellation and after updating.
- Automatic checks remain quiet and limited to once a day. They do not download or install anything without a tap. **View release** remains available for reading the changes.

Install this APK over your existing Spotygram once to gain the in-app installer for subsequent releases. Older versions cannot acquire an installer without being updated themselves. ARM64 is the phone build; x86-64 is for x86-64 Android environments.
