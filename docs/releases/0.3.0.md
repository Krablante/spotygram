# Spotygram 0.3.0 — язык, навигация и очередь

Приложение запоминает последний открытый раздел. Вкладки теперь идут слева направо: **Чаты → Любимые → Плейлисты → Музыка**.

Добавлены русский и английский интерфейсы с автоматическим выбором по языку телефона и английским по умолчанию для других языков. На Android 13+ пункт **Настройки → Язык** открывает системный выбор языка приложения.

Очередь переработана для больших подборок: плеер и системный медиаконтроллер получают только предыдущую, текущую и следующую запись. Остальная подборка остаётся списком идентификаторов. Перемешивание работает с индексами, а обновление позиции больше не затрагивает весь экран библиотеки. Сохранённая очередь предыдущих версий переносится без сброса данных и без автозапуска.

**Для телефона: `spotygram-0.3.0-arm64.apk`.** Установи поверх предыдущей версии, не удаляя приложение. Постоянный ключ подписи и `app.spotygram` сохранены. Отдельный x86-64 APK предназначен для соответствующих Android-устройств и эмуляторов.

Проверенные сценарии и ограничения описаны в [verification.md](../verification.md). Работа с реальным большим Telegram-чатом и поведение на физическом ARM64-телефоне не подменяются проверкой локальной очереди в эмуляторе.
