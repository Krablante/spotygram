# Spotygram 0.4.0 — абсолютный рандом и высота плеера

Кнопка порядка воспроизведения теперь переключает три режима: **по порядку → перемешивание без повторов → абсолютный рандом**. У третьего режима значок кубика и понятная подпись. Каждая новая следующая песня выбирается независимо, включая возможность повториться сразу. Рандом работает бесконечно; повтор одной песни остаётся доступен.

Плеер использует высоту экрана: свободное место распределяется между блоками, а нижние действия не остаются высоко над системной навигацией. При недостатке места или крупном шрифте содержимое прокручивается.

Для рандома хранятся только 32 предыдущих выбора, текущий и следующий. Медиасессия по-прежнему получает максимум три записи, а полная подборка не пересохраняется при каждом переходе. Прежние режимы, очередь и позиция переносятся без сброса данных.

**Для телефона: `spotygram-0.4.0-arm64.apk`.** Установить поверх предыдущей версии, не удаляя приложение. Подпись и идентификатор `app.spotygram` сохранены. Результаты ручных проверок и их пределы — в [verification.md](../verification.md).
