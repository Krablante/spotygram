# Spotygram 0.5.0 — очистка кэша музыки

В **Настройках → Очистить кэш музыки** появился размер скачанной музыки Telegram, число файлов, обновление размера, подтверждение удаления и отчёт об освобождённом месте.

Очистка включает **все локальные копии аудио Telegram**, в том числе скачанные специально для офлайна. Перед удалением это явно объясняется. Воспроизведение и загрузки останавливаются; позиция остаётся для ручного продолжения. Импортированные записи, любимые, плейлисты и вход в аккаунт сохраняются.

Файлы удаляет штатный механизм TDLib — база аккаунта и папки импортированной музыки не очищаются. Если исходное сообщение уже удалено из Telegram, восстановить стёртую локальную копию не получится.

**Для телефона: `spotygram-0.5.0-arm64.apk`.** Установить поверх предыдущей версии без удаления приложения. Постоянная подпись и `app.spotygram` сохранены. Проверенные сценарии и ограничения приведены в [verification.md](../verification.md); очистка непустого кэша авторизованного аккаунта не выдаётся за локально проверенный сценарий.
