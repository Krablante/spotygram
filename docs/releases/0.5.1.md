# Spotygram 0.5.1 — дубли в «На телефоне»

Исправлено расхождение: настройки считали уникальные локальные файлы, а список «На телефоне» показывал каждую ссылку из сообщений. Теперь оба используют одну коллекцию: **один файл — одна строка**. При одинаковых фильтрах счётчики согласованы.

Выделение и запуск подборки не включают скрытые копии одного файла. Подсветка текущей песни узнаёт её через другую ссылку на тот же файл. Сердечко учитывает отметки группы, а отмена снятия отметки возвращает прежние значения. Удаление копии также учитывает общий путь и не позволяет удалить файл текущей песни через другую строку.

Исходные сообщения, записи каталога и плейлисты не удаляются. Одинаковое название не считается доказательством дубля: разные локальные файлы остаются разными записями.

**Для телефона: `spotygram-0.5.1-arm64.apk`.** Установить поверх предыдущей версии, не удаляя приложение. Результаты ручной проверки — в [verification.md](../verification.md).
