# 0.11.1 — restore the 0.10.3 app

This release restores the app from 0.10.3, including its light and dark
appearance, background, glass surfaces, navigation and player controls.
The application code and dependencies match 0.10.3; only the app version
has changed.

The new version number allows installation over 0.11.0 as a normal update.
Install it over the existing app to keep your local music, playlists,
settings and Telegram session. There are no library or account migrations.
