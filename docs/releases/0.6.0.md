# Spotygram 0.6.0

Public release with quiet GitHub update checks.

- Automatic checks happen only when opening/returning to the app, at most once in 24 hours. Failed attempts count too; no background scheduler or retries.
- A newer release appears in a dismissible library banner. Dismissal survives restarts for that version. No-update results and automatic errors stay silent.
- Settings includes an automatic-check switch, manual check with visible results, and a link to the newer release. Repeated manual checks have a one-minute floor and respect GitHub rate limits.
- Nothing downloads or installs automatically. The release opens in the browser, without a GitHub account/token in the app.
- Existing playback, account, library and signing identity are retained.

Install the **ARM64 APK** on phones; the **x86-64 APK** is for x86-64 Android environments. Android 8.0+. This is an early public build; ordinary GitHub releases are now the update channel, while prereleases remain excluded. See `docs/verification.md` for observed checks and limits.
