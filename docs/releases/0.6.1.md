# Spotygram 0.6.1

Fixes local Telegram file bindings that could leave a song pointing to a non-audio file after a restart.

- Discard stale numeric TDLib file IDs before processing new file updates. New bindings come from messages resolved in the current client.
- Check local copies against the known audio size. Mismatched catalog paths are cleared without deleting files, favorites or playlists; accessible Telegram originals can be resolved again.
- Resolve the current file ID before explicit removal of a Telegram copy.
- Open personal-chat messages through Telegram Android instead of requesting an unavailable HTTPS message link.
- Show readable playback errors and replace stale queued notices rather than replaying technical exceptions.

Install over the existing app to retain your data. ARM64 is the phone build; x86-64 is for x86-64 Android environments. No new decoder, background scanner or automatic cache deletion was added.

The supplied MP3 played in both the previous debug and signed builds. A wrong-path catalog condition reproduced the reported extractor error. Verification details and limits are in `docs/verification.md`; the exact file mapping on the reporting phone was not available for inspection.
