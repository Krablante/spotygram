# 0.10.0 — Liquid Glass interface

Spotygram has a new light and dark interface with a prismatic background,
translucent search and source controls, floating navigation and mini-player,
and a glass frame and transport surface in the full player. Chats and playlists
use the same materials. Settings now offers only light and dark; before a choice,
the app follows the phone's appearance.

The launcher icon, Android window colors and README artwork now use the same
violet, rose and cyan palette.

The music list remains lazy and its individual track rows do not run blur or
shaders. Chat track counts are computed once per library snapshot instead of
scanning all tracks for each visible source. Wide layouts limit the main column
to 720 dp.

The app and signing identity are unchanged. Updating over 0.9.2 keeps local
music, playlists, favorites and the Telegram session.
