# Spotygram 0.2.0 — Всё под рукой

Интерфейс переработан по выбранному варианту C: четыре раздела, видимые любимые и полноценная работа с плейлистами. Репозиторий и релиз остаются приватными.

**Для телефона: `spotygram-0.2.0-arm64.apk`.** Установи поверх 0.1.x, не удаляя приложение. Идентификатор `app.spotygram` и постоянный ключ подписи сохранены. История Telegram по-прежнему загружается целиком, без ограничения в 100 треков.

## Музыка и любимые

- Четыре прямых раздела: **Музыка / Любимые / Плейлисты / Чаты**.
- Компактная шапка, мягкий зелёный акцент и одинаковые возможности светлой и тёмной тем.
- Сердечко у каждой песни. Снятие отметки можно отменить; оно не удаляет файл и не останавливает музыку.
- Любимые — отдельный экран, не временный фильтр. Фильтр «На телефоне» из музыки на него не переносится.
- Зажатие песни включает выделение с системным тактильным откликом. В этом режиме нажатия выбирают песни, а не запускают их. Есть также явная кнопка «Выбрать».
- Поиск не сбрасывает выделенные песни. «Назад» сначала снимает выделение, смена раздела завершает его. Поиск и выделение сохраняются при повороте экрана.

## Плейлисты

- Заметная кнопка **«Новый плейлист»** и полный экран создания: название и выбор песен сразу. Можно начать с пустого плейлиста.
- Выделенные песни добавляются в существующий или новый плейлист одной операцией. Повторное добавление не создаёт дубликатов.
- Добавление песен, переименование, подтверждение удаления и удаление выбранных песен только из подборки.
- Перетаскивание за ручку с прокруткой у края списка; стрелки выше/ниже как альтернативное управление. Порядок сохраняется при отпускании.
- Обложки из имеющихся изображений песен или простой значок, если изображений нет. Отдельная генерация обложек не требуется.
- При удалении импортированного файла его записи убираются также из очереди: плеер не переключается на уже удалённую песню.

## Сенсорный интерфейс и простота

Основные цели касания — не меньше 48 dp, строки — не меньше 64 dp. Перемещение и лайки используют стандартный Android haptic feedback и визуальный отклик. Клавиатура не перекрывает создание плейлиста и не возвращается сама после добавления из поиска. Горизонтальная компоновка экономит высоту. Проверена читаемость нижней навигации с системным шрифтом 130%.

Новых зависимостей, серверов и фоновых сервисов нет. Массовые изменения записываются транзакцией с одним обновлением библиотеки, перетаскивание не пишет в базу на каждом движении пальца. Музыкальному списку не передаются тики позиции плеера.

## Проверка

Проверка ручная, на Android 16 x86-64, через интерфейс и логи. Результаты и границы — в `docs/verification.md`. Физический тактильный отклик, задержки на телефоне и авторизованный Telegram-сценарий здесь не измерялись; выпуск остаётся alpha.

APK подписан прежним сертификатом; SHA-256 файлов находится в `SHA256SUMS`.
