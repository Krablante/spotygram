# Spotygram 0.13.0 — скорость воспроизведения

Круглая кнопка под Play, между **Скачать** и **Очередь**, показывает текущую
скорость. Нажатие открывает компактную стеклянную панель:

- Ползунок от **0,3× до 4×**.
- **− / +** для точной подстройки с шагом 0,05×.
- Быстрые значения **0,5× · 1× · 1,5× · 2× · 3×**.

Темп меняется сразу, без кнопки подтверждения, с сохранением высоты голоса.
Выбранная скорость действует для следующих треков и после перезапуска.
**1×** возвращает обычный темп. Изменённая скорость также видна в мини-плеере.

Светлая и тёмная темы сохраняют существующий стеклянный стиль. Кнопки и ползунок
имеют удобные области касания; при крупном шрифте на узком экране нижние действия
показываются иконками. Используется существующий Media3-плеер, без новых
зависимостей или фоновых служб. Обновление устанавливается поверх предыдущей
версии с сохранением библиотеки, плейлистов и настроек.
