# Документация

[Spotygram](../README.ru.md) · [English](README.md) · **Русский**

Если хочешь установить плеер и слушать музыку, начни с руководства
пользователя. Документы для разработки объясняют, как собрать APK и
как устроено приложение.

| Руководство | Что внутри |
| --- | --- |
| [Как пользоваться](usage.md) | Вход, источники музыки, плейлисты, офлайн, очистка места и обновления |
| [Сборка и выпуск](build.ru.md) | Инструменты, API-данные, подпись APK и релизы на GitHub |
| [Устройство приложения](architecture.ru.md) | Работа с Telegram, библиотека, воспроизведение и проверка обновлений |
| [Журнал проверок](verification.md) | Что проверено на практике, каким способом и что ещё не проверялось |
| [Сторонние компоненты](third-party.md) | Зависимости и лицензии |

Первые три руководства доступны на обоих языках; переключатель находится
вверху каждой страницы. Исторический журнал проверок и заметки к выпускам
ведутся на английском. Скачать APK и посмотреть изменения можно
на [странице релизов](https://github.com/Krablante/spotygram/releases).
